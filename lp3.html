浏览器端网页录屏工具

纯前端实现，无需安装软件，不上传云端，所有视频保存在本地浏览器。支持屏幕、窗口、标签页录制，麦克风+系统音频，直接导出WebM视频文件。

核心功能

🔒 本地处理，隐私安全

所有视频数据全部在浏览器内处理，不会发送到任何服务器，保护你的屏幕内容隐私。

🎙️ 双音频录制

支持麦克风输入与电脑系统声音，可独立开关，同时录制讲解声音与电脑内部音频。

⚙️ 帧率可调

15/24/30帧可选，适配不同场景，兼顾视频清晰度与文件体积大小。

🖥️ 录制任意屏幕源

可选择录制整个屏幕、单独应用窗口、浏览器标签页，鼠标光标可被录制。

💾 一键导出下载

录制结束直接下载WebM视频，主流播放器全部支持播放。

📦 单HTML文件

只有一个HTML，无依赖，复制保存或者直接下载源码文件即可运行，可部署到任意静态网页服务器。

快速使用教程

操作步骤

  1. 点击【在线体验】打开录屏面板
  2. 勾选需要的音频选项（麦克风、系统音频），选择录制帧率
  3. 点击开始录制，浏览器弹出窗口，选择要录制的屏幕/窗口/标签，确认共享
  4. 录制完成点击停止，即可下载视频

浏览器兼容性提示

✅ 推荐：Chrome / Edge浏览器
⚠️ Firefox部分支持
❌ Safari兼容性较差，容易出现录制异常

<script>
    const startBtn = document.getElementById('startBtn');
    const stopBtn = document.getElementById('stopBtn');
    const statusEl = document.getElementById('status');
    const emptyTip = document.getElementById('emptyTip');
    const warnTip = document.getElementById('warnTip');
    const videoList = document.getElementById('videoList');
    const fpsSelect = document.getElementById('fpsSelect');
    const micCheck = document.getElementById('micCheck');
    const audioCheck = document.getElementById('audioCheck');
    let mediaStream = null;
    let mediaRecorder = null;
    let chunks = [];
    let timer = null;
    let seconds = 0;
    function addVideoRecord(blob) {
        if (!blob || blob.size <= 0) {
            warnTip.style.display = 'block';
            setTimeout(()=>warnTip.style.display='none', 3000);
            return false;
        }
        warnTip.style.display = 'none';
        emptyTip.style.display = 'none';
        const url = URL.createObjectURL(blob);
        const item = document.createElement('div');
        item.className = 'video‑item';
        item.innerHTML = `
            <span>录制视频 ${new Date().toLocaleString()} (${(blob.size/1024/1024).toFixed(2)}MB)</span>
            <a class="download‑btn" href="${url}" download="screen_${Date.now()}.webm">下载</a>
        `;
        videoList.appendChild(item);
        return true;
    }
    function resetTimer(){
        clearInterval(timer);
        seconds=0;
    }
    function startTimer(){
        resetTimer();
        timer = setInterval(()=>{
            seconds++;
            const m = String(Math.floor(seconds/60)).padStart(2,'0');
            const s = String(seconds%60).padStart(2,'0');
            statusEl.textContent = `录制中 ${m}:${s}`;
        },1000);
    }
    startBtn.onclick = async ()=>{
        try {
            const fps = Number(fpsSelect.value);
            const displayMediaOptions = {
                video:{
                    cursor:"always",
                    frameRate:{ideal:fps}
                },
                audio: audioCheck.checked
            };
            mediaStream = await navigator.mediaDevices.getDisplayMedia(displayMediaOptions);
            if(micCheck.checked){
                const micStream = await navigator.mediaDevices.getUserMedia({audio:true});
                const audioTracks = micStream.getAudioTracks();
                mediaStream.addTrack(audioTracks[0]);
            }
            chunks = [];
            const options = {mimeType: 'video/webm;codecs=vp9,opus'};
            if(!MediaRecorder.isTypeSupported(options.mimeType)){
                options.mimeType = 'video/webm';
            }
            mediaRecorder = new MediaRecorder(mediaStream, options);
            mediaRecorder.ondataavailable = (e)=>{
                if(e.data && e.data.size>0) chunks.push(e.data);
            }
            mediaRecorder.onstop = ()=>{
                resetTimer();
                statusEl.textContent = "录制完成";
                const blob = new Blob(chunks, {type:'video/webm'});
                addVideoRecord(blob);
                mediaStream.getTracks().forEach(t=>t.stop());
            }
            mediaRecorder.start();
            startTimer();
            startBtn.style.display = 'none';
            stopBtn.style.display = 'block';
            mediaStream.getVideoTracks()[0].onended = ()=>{
                mediaRecorder.stop();
            }
        }catch(err){
            statusEl.textContent = "启动失败："+err.message;
            console.error(err);
        }
    }
    stopBtn.onclick = ()=>{
        if(mediaRecorder && mediaRecorder.state !== 'inactive'){
            mediaRecorder.stop();
        }
        startBtn.style.display = 'block';
        stopBtn.style.display = 'none';
    }
</script>

常见问题 FAQ

Q：录制出来视频是空的？
不要点击开始立刻停止录制，至少录制2秒以上。浏览器需要采集足够视频帧，时间太短会生成空视频文件。
Q：无法录制系统内部声音？
Windows笔记本需要开启立体声混音；部分浏览器环境对系统音频捕获支持有限，可以只录制麦克风。
Q：为什么不能在本地file协议打开录屏？
新版Chrome允许本地文件屏幕共享；如果报错，把html放到静态web服务器运行（http/https）。
Q：输出WebM怎么转为MP4？
可以使用剪映、格式工厂、FFmpeg把webm转换成MP4格式。
